# Kutumb Cashflow

Kutumb Cashflow is a Vite + React + TypeScript family finance tracker for the Indian market. It ships with public marketing pages, Supabase-powered auth, private finance dashboards, and INR-first number formatting.

## Stack
- React 18 + TypeScript 5 + Vite 5
- Tailwind CSS v3 with shadcn-style UI primitives
- Framer Motion, React Router, React Query
- Supabase client for auth and data access

## Environment variables
Create a `.env` file using `.env.example`:

```bash
VITE_SUPABASE_URL=https://placeholder.supabase.co
VITE_SUPABASE_ANON_KEY=placeholder-key
```

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
