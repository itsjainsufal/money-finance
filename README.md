# MoneyFlow Family Finance

MoneyFlow is a creator-ready family budgeting web app built with React 18, Vite, Tailwind CSS, React Router, Recharts, and localStorage persistence.

## Included features

- Dashboard with net worth, spending, budget, and advisor highlights
- Budget manager with progress tracking
- Transactions ledger with filters and CRUD
- Financial goals with deadlines and progress
- Recurring bills/subscriptions tracker
- Multi-currency reporting with built-in exchange rates
- Family members with assigned transactions and private net worth
- Rule-based AI spending advisor
- Net worth tracker with historical chart
- Dark/light mode and responsive layout

## Run locally

```bash
npm install
npm run dev
```
